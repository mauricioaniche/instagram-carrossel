# Trilhas locais

Adicione aqui arquivos MP3, WAV, M4A, AAC, FLAC ou OGG que você tenha autorização para usar. Novas trilhas são ignoradas pelo Git. A CLI escolhe uma automaticamente; `--music nome.mp3` seleciona uma faixa específica.

Os três MP3 já versionados não possuem comprovantes de licença neste repositório. Antes da distribuição pública, confirme suas licenças ou remova-os também do histórico do Git. A regra de ignore não remove arquivos já rastreados.
